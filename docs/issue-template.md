# Issue / 任务单模板

## 目标行为

用户或业务最终能完成什么。

## 用户可见结果

页面、订单、支付、库存、消息、后台数据等可观察变化。

## 涉及领域概念

引用 `CONTEXT.md` 中已有术语；如出现新术语，先澄清再补充。

## 验收标准

1. 成功路径。
2. 失败路径。
3. 边界条件。
4. 测试或冒烟验证方式。

## 不在本次范围

明确排除项。

## 是否 AFK / HITL

AFK：AI 可以离线自主完成。
HITL：Human in the loop，中文意思是“需要人参与确认”。

## 依赖项

接口、设计稿、账号、测试数据、权限或其他任务。

## 项目边界提醒

这是 kangaroo-japan 前端，不是 kangaroo-shop。对应后端路径是 ~/workspace/kangaroo-japan-backend/，数据库是 Vercel Storage 的 daishujundulizhan 库。
