# Agent Brief 模板

用于把任务交给达摩院、claude-coder、Codex 或 Claude Code 前整理上下文。

## 项目

kangaroo-japan 袋鼠君日本代拍独立站前端

## 任务摘要

一句话说明要达成什么用户可见结果。

## 当前行为

现在系统是什么表现；如果是新功能，写“当前没有该能力”。

## 期望行为

用户完成什么动作后，应该看到什么结果。

## 涉及范围

页面 / API / 数据 / 配置 / 测试 / 文档。

## 验收标准

1. 可以被用户或测试明确验证的结果。
2. 必须包含成功路径。
3. 如有必要，包含失败路径和边界条件。

## 不在本次范围

明确写不做什么，防止 AI 顺手扩大范围。

## 反馈环

用什么验证：测试、脚本、curl、浏览器、日志、录屏或人工验收。

## 风险与权限边界

是否涉及生产配置、数据库、支付、客户资料或对外发布；如涉及，必须先请花哥批准。

## 项目边界提醒

这是 kangaroo-japan 前端，不是 kangaroo-shop。对应后端路径是 ~/workspace/kangaroo-japan-backend/，数据库是 Vercel Storage 的 daishujundulizhan 库。
